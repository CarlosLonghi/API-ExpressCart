# ExecPlans

Stores executable specifications for refactor phases and features. See `.claude/PLANS.md` for the full spec and when to write one.

## Usage

```bash
cp .claude/execplans/TEMPLATE.md .claude/execplans/YYYY-MM-DD-name.md
```

Fill it out as you work; commit it alongside the change. Naming: `YYYY-MM-DD-name.md`.
